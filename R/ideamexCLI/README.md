# IDEAMEX-CLI

**IDEAMEX-CLI** (*Integrative Differential Expression Analysis for Multiple EXperiments*) es una **interfaz de línea de comandos (CLI)**, desarrollada en **R** para el análisis e integración de resultados de **expresión diferencial de datos de RNA-seq**. Permite ejecutar de forma automatizada los paquetes de [**Bioconductor**](https://bioconductor.org/): [**DESeq2**](https://bioconductor.org/packages/release/bioc/html/DESeq2.html), [**edgeR**](https://bioconductor.org/packages/release/bioc/html/edgeR.html), [**limma–voom**](https://bioconductor.org/packages/release/bioc/html/limma.html) y [**NOISeq**](https://bioconductor.org/packages/release/bioc/html/NOISeq.html), e integrar sus resultados mediante herramientas gráficas y archivos de texto.  

Su objetivo es facilitar un análisis integral, **reproducible** y **visual** de datos provenientes de diferentes condiciones experimentales.
